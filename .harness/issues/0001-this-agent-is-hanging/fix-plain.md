When you started an agent, its panel sometimes stayed completely black with
"Starting" at the top and never went any further, however long you waited.
Closing it and starting again usually worked, which is why it felt random.

It was not the agent. In the first instant after an agent starts, the panel
tells it how big it is — and on Windows, if that message arrives during a
very short moment while the agent is still being set up, everything freezes
before it can draw anything. That moment is wider for Claude than for simpler
programs, and wider still when the computer is busy, which is why it came in
bursts.

The size message now waits until the agent is ready for it, then goes
through. Agents start every time; nothing else changes.

You will need to rebuild and restart the harness for this to take effect.
